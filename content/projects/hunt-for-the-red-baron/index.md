description: I was the sole programmer on this project, along with an artist and
  a game designer. The game was designed to be purchased and downloaded over the
  internet over a 56kbs modem, so the entire download size was limited to 15MB.
  The game used Renderware and an internal engine developed at Criterion. The
  game was a 3D WWI flight combat game, and I wrote all the code for the game,
  including the vehicle dynamics, audio, VFX, menu system, AI, and game
  progression. The project was completed in around six months, and was the
  best-selling game from Fiendish Games at the time.
